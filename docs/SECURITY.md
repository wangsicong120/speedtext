# 安全与隐私边界

## 已采取的措施

- 后端只读：健康状态、当前请求的边缘信息、公开默认配置。没有任意 URL fetch、下载中继、上传或持久化存储，避免将服务变成 SSRF/带宽滥用代理。
- API 检查 `Origin` 与 `Sec-Fetch-Site`，拒绝跨站及同站不同源请求；不开放 CORS，不接受查询参数。该检查不是身份认证，非浏览器客户端仍能请求公开 API，但只能查询自身请求的信息。
- 生产 HTML/JS/CSS 和 API 经过同样的 CSP、安全响应头与 HTTPS HSTS。脚本和样式只允许本地来源，不允许 `unsafe-inline`、`unsafe-eval`、对象、表单提交或页面嵌入。
- 所有节点名称、IP 服务文本和错误结果通过文本节点显示，不插入 HTML，不执行下载内容。不从 CDN 引入任何前端运行时第三方脚本。
- 仅接受 HTTPS 公开域名格式，拒绝 URL 凭据、IP 字面地址、明显本地/内部域名、控制字符及过长输入。查询签名字节默认保留，随机参数需手动开启。
- 下载和探测均使用 `credentials: omit`、`referrerPolicy: no-referrer`、`cache: no-store`；读响应流，不把大文件完整缓存到内存。
- 可选下载限额、独立时长定时器、连接/空闲读取超时、可取消退避、会话隔离和有限采样队列；旧请求不能污染新统计。
- 自动网络检测串行调度各轮、限制小响应读取并设超时；后台、离线、关闭自动检测或离开页面可取消，旧生命周期响应不能覆盖新结果。外部 IP 经过格式校验，来源明确标注。
- 本地模式不信任伪造的 `CF-Connecting-IP`/`X-Forwarded-For`。生产只使用 Cloudflare 提供的请求元数据，不把浏览器提交的自报 IP 当作权威数据。
- 依赖版本锁定；CI 只读权限、Actions 固定提交，不获取 Cloudflare 凭据，不自动部署。

## 不承诺的事项

### 流量预算不是账单硬上限

字节值是浏览器交给 JavaScript 的响应体数据，可能是解压后的内容；没有计算 HTTP/TLS/链路开销、重试开销或取消前已发送的在途数据。一次读取块可能超过剩余预算；到限额后立即发出取消，但实际网络流量仍可能更大。浏览器后台冻结或系统调度也可能推迟时长停止。

流量上限与自动停止默认关闭（有效值均为 `0`），不勾选就不会生效；旧版隐式 `100 MiB / 60 秒` 不会自动恢复为启用。两项都关闭时开始前需额外确认，测试仍可能持续产生高额流量费用，使用者需手动停止并控制资源权限。显式启用的限额与采样 `8 MiB / 8 秒` 均只是客户端停止条件，不是运营商计费保证。

### 地址校验不能证明 DNS 或重定向安全

公开域名可解析到私有地址、发生 DNS 重绑定或重定向。浏览器网络层会先处理 DNS/重定向；页面只能校验输入和可读取响应的最终 URL，无法在请求前可靠审核全部跳转。因此依赖 HTTPS、浏览器的 CORS/本地网络访问保护，以及使用者对目标的信任；不是完整客户端内网隔离器。

`connect-src 'self' https:` 是支持用户自定义公开 HTTPS 下载的必要边界，不等于域名白名单。不要通过关闭浏览器安全策略或改成代理来绕过失败节点。

### CORS 与连通性

支持 CORS 的响应才能读取字节测速。浏览器的 `TypeError` 也可能来自 DNS、TLS、离线或网络拦截，提示不会把它确定归因为 CORS。

第三方连通性使用 `no-cors` 获取 opaque 响应，只知道响应到达/耗时，无法检查 HTTP 状态；结果仅显示耗时（ms），500、登录失败或受限页面仍可能显示数值，不代表 HTTP 成功或服务可登录。本站延迟是 HTTP 首响应，不是 ICMP Ping。短文件采样也不能证明峰值带宽。

首次推荐的测速节点不代表全网可用；保存的下载地址不会被自动替换。节点采样仍需用户确认，不会因自动 IP/连通性检测而批量下载历史节点。代理、VPN、IPv4/IPv6 与分流策略可能让各 IP 服务观察到不同地址；第三方结果不是本站边缘数据，也不证明下载目标使用相同出口。

### 本地配置和日志

节点、当前完整 URL、主题、选项和采样结果存于当前站点的浏览器 localStorage，不上传到后端。共享设备上的同源脚本或有权限的扩展仍可能读取；清除浏览器站点数据可移除保存内容。存储被拒绝时可继续在内存中使用，但无法持久化。

统计导出不含完整下载 URL/签名查询参数，但包含自定义节点名称；“复制节点结果”包含完整 URL。分享前检查。第三方下载/IP/连通性目标会看到本次请求的出口 IP。

出口 IP/连通性默认在打开页面时检测，每轮完成后约 30 秒再次请求小响应：ipip.net、ipinfo.io（失败时回退 ipify）及百度、Cloudflare、GitHub、YouTube 图标。请求不携带凭据或 referrer；本站 API 和 ipinfo 失败后冷却 5 分钟，手动刷新或重新联网可强制重试。可关闭自动刷新，偏好只存于当前浏览器；后台或离线时暂停，之前结果可能过期。手动刷新仍会访问这些服务。下载中的同源首响应测量独立于第三方自动刷新。

应用不建立 IP 数据库，也不打印 IP、签名 URL 或查询参数。Cloudflare/CDN、目标服务器和浏览器仍有各自的元数据、日志、计费和隐私政策，不能保证它们不留存数据。

### 保活、静态托管与历史资源

伪熄屏只是黑色页面弹窗，不关闭真实屏幕。Wake Lock 和本地静音音频只尽力保活，系统锁屏、节电或后台冻结仍可暂停；拒绝权限时不尝试绕过。

纯静态托管没有本站边缘 API，IP 自动回退到明确标注的第三方来源，本站首响应用同源图标测量；服务不可读时显示未测得，不伪造成功结果。若托管商不支持 `_headers`，还需单独配置安全响应头。新版构建仅包含新前端，仓库保留的旧资源不被引用，也不能据此认定旧代码已被全面加固。

## 报告问题

可在仓库提交不含个人信息和令牌的最小复现。涉及可利用漏洞时，不要公开敏感 URL、真实 IP 或利用载荷，先通过仓库维护者提供的私密渠道联系。修复后需复跑相关单元、workerd、浏览器与安全头测试。
