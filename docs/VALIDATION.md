### 依赖审计覆盖

本轮执行 **全量** `npm audit --json --fetch-retries=2 --fetch-timeout=60000`，成功返回 **0 个已知漏洞**，包含可选依赖，没有使用 `--omit=optional`。

## 覆盖的关键行为

- 下载：HTTPS/域名/凭据校验、签名查询参数保留、先验证首块再扩展并发、流量/时长停止、连接及流式读取超时、有限 HTTP/CORS 重试。
- 默认设置：流量上限与自动停止独立开关，默认关闭、有效值均为 `0`；不自动下载，不限量开始前仍需确认。显式开关可保存，旧版隐式 `100 MiB / 60 秒` 不重新启用。
- 取消：停止所有连接、取消读取和退避，旧会话不能污染新统计；离线停止，联网后不自动启动。
- 节点：原版分组逐条迁移，自定义文本不执行 HTML，搜索、重复 URL 隐藏、撤销、损坏/被拒绝的存储回退。
- 节点恢复：首次推荐现有 Cloudflare 测速节点，不覆盖保存的选择；失败后可切换推荐节点或进入检测，不静默更换、不增加后端下载代理。
- 采样：URL 去重、4 并发上限、读取预算、关闭弹窗即取消、重新采样不接收旧结果、手动复制回退。
- 交互：失焦校验不再移走鼠标下方的开始按钮，错误聚焦到相关字段；主题持久化、键盘跳转、弹窗焦点、Escape、伪熄屏、统计导出脱敏。
- 自动网络检测：每轮完成后约 30 秒刷新，关闭偏好持久化；并发刷新共享一轮，后台/离线/离开页面取消，恢复时刷新，迟到响应不能覆盖新生命周期结果。
- IP 与静态回退：优先本站边缘；静态 HTML、404、CORS 或限流时回退到明确标注的第三方 IP，同源图标测本站首响应；IP 格式校验、响应体读取上限、API/ipinfo 五分钟冷却及非滑动截止时间。
- 后端：只读方法、HEAD、同源检查、无代理出口、查询参数拒绝、安全头、真实静态文件、未知路径与测试流路径 404、本地伪造转发头无效。

### 原生浏览器 API 回归

实际页面复现了类成员直接调用原生 `Window.fetch`、`setTimeout` / `clearTimeout` 的 `Illegal invocation`：下载被误报为 CORS/网络不可达，连通性失败，自动刷新中断。已改为无接收者调用包装。

修复前新增浏览器用例确实失败；修复后 `tests/e2e/native-api.spec.js` 的两个场景在两个项目中全部通过：

- 不替换 `window.fetch`、不安装 `page.clock`，用本地构造的 HTTP 响应验证一次可读的 64 KiB 下载及限额停止。
- 使用真实 30 秒定时器等待第二轮检测完成，再验证关闭自动刷新后的手动刷新；无页面错误、不触发下载。

单元测试另检查注入的 fetch 与定时器不会收到类实例作为 `this`。常规界面测试仍使用固定小响应，不把模拟 API 的成功当作原生 API 的证明。

### 测试不产生大规模真实下载

下载/采样使用显式启用的本地模拟流。第三方响应由本地构造；CORS 和 opaque 响应测试通过 Chromium CDP 提供 HTTP 响应，保留浏览器自身安全判断，避免 Playwright `route.fulfill` 自动补 CORS 头或取消 `favicon.ico` 造成假阳性。

没有关闭 CORS、证书校验或浏览器安全功能。自动化验证证明逻辑和交互行为，不证明历史第三方节点当前可用、峰值带宽或免流。下方单独记录的一次真实下载也不是批量节点可用性测试。

## 补充实测

### Cloudflare 本地开发模式

在 `npm run dev` 的真实 Cloudflare/Vite 页面检查本轮功能：

- 根入口为完整新页面，JS/样式、开始按钮正常；当前版本显示 `v3.1.0`，限制默认关闭。
- 本地模式没有权威边缘 IP，页面自动取得有效第三方 IP 并显示来源；修复后没有未捕获的 `Illegal invocation`。
- 本轮真实检测中，百度、Cloudflare、GitHub 曾显示“响应到达”；YouTube 未测得，后续 GitHub 也曾超时。按实际结果展示，不把 opaque 响应冒充 HTTP 成功。
- 本地伪造转发头无效、生产/Preview 不携带 `LOCAL_DEV` 的边界仍由本轮单元测试、真实 workerd 与构建检查覆盖。

### 独立静态与手机布局

额外在只提供静态文件、没有 API 的本地服务器 `http://127.0.0.1:4180/speedtext/` 打开最终构建产物：

- 相对 JS、CSS、图标路径正确；不存在本站 API 时取得有效第三方 IP，明确显示静态回退与来源，同源图标首响应有效。
- 独立浏览器补查 **375 × 812** 竖屏、**844 × 390** 横屏的深浅主题主页与添加节点弹窗，无横向溢出、无未捕获页面错误。竖屏弹窗宽度/滚动宽度均为 373 px，横屏均为 842 px。
- 手机检查保持原生 fetch/定时器；第三方 HTTP 小响应由 CDP 本地构造，每个主题 6 次检测请求、不启动下载。深浅主题主页与添加弹窗的 4 张截图已人工查看；截图中的示例 IP/连通性不是实际外网可用性证明。
- E2E 另覆盖 375 × 812、844 × 390、768 × 1024、1440 × 900 布局、减少动画及主要按钮至少 44 × 44 CSS px。

### 一次小流量真实下载

在上述静态页面，不安装网络模拟，使用原生 fetch 直连 `https://speed.cloudflare.com/__down?bytes=65536`：

- 单并发，显式启用 **0.0625 MiB（64 KiB）** 流量上限及 **8 秒**时长上限，随机参数关闭。
- 页面实际读取 **64 KiB**，约 **2 秒**后显示“已达到流量上限，自动停止”；资源记录中只有一次该下载请求，结束后恢复“开始测试”。

该结果只证明此节点在本次网络中可读及客户端停止逻辑正常，不代表全部历史节点、用户所在网络或峰值带宽。64 KiB 是 JavaScript 读取的响应体，不是协议开销或账单硬上限。
