最初执行 `npm audit --omit=optional --json --fetch-retries=2 --fetch-timeout=60000`，返回 0 个已知漏洞；此前全量审计曾因 npm registry TLS 连接中断而未取得结果。

网络恢复后，重新执行 **全量** `npm audit --json --fetch-retries=2 --fetch-timeout=60000`，成功返回 **0 个已知漏洞**，本次包含可选依赖，没有使用 `--omit=optional`。

该结果仅代表验证时 npm advisory 数据库报告的已知漏洞，不证明依赖树或供应链没有风险。未关闭 TLS 校验、换用不可信源或自动升级依赖；锁定的依赖没有变化。

## 覆盖的关键行为

- 下载：HTTPS/域名/凭据校验、签名查询参数保留、先验证首块再扩展并发、流量/时长停止、连接及流式读取超时、有限 HTTP/CORS 重试。
- 取消：停止所有连接、取消读取和退避，旧会话不能污染新统计；离线停止，联网后不自动启动。
- 节点：原版分组逐条迁移，自定义文本不执行 HTML，搜索、重复 URL 隐藏、撤销、损坏/被拒绝的存储回退。
- 采样：URL 去重、4 并发上限、读取预算、关闭弹窗即取消、重新采样不接收旧结果、手动复制回退。
- 交互：失焦校验不再移走鼠标下方的开始按钮，错误聚焦到相关字段；主题持久化、键盘跳转、弹窗焦点、Escape、伪熄屏、统计导出脱敏。
- 后端：只读方法、HEAD、同源检查、无代理出口、查询参数拒绝、安全头、真实静态文件、未知路径与测试流路径 404、本地伪造转发头无效。

### 测试不产生大规模真实下载

下载/采样使用显式启用的本地模拟流。第三方响应由本地构造；CORS 和 opaque 响应测试通过 Chromium CDP 提供 HTTP 响应，保留浏览器自身安全判断，避免 Playwright `route.fulfill` 自动补 CORS 头或取消 `favicon.ico` 造成假阳性。

没有关闭 CORS、证书校验或浏览器安全功能。该验证证明逻辑和交互行为，不证明历史第三方节点当前可用、峰值带宽或免流。
