# 驾驶舱视觉层

Speedtext 沿用联通资源驾驶舱的设计语言；本轮仅清理测速地址、取消节点分组并统一原“自定义下载”名称，下载设置、仪表和网络检测布局保留。

## 令牌

| 用途 | 深色 | 浅色 |
|---|---|---|
| 页面背景 | `#0c101a` | `#f4f7fb` |
| 面板 | `#121927` | `#ffffff` |
| 次级面板 / 控件 | `#182131` | `#eef2f8` |
| 主要文字 | `#e8edf5` | `#1d2129` |
| 次要文字 | `#86909c` | `#52606f` |
| 链接 / 强调 | `#86baff` | `#0e5fd8` |
| 主操作填充 | `#1677ff` | `#1668dc` |
| 正常 / 预警 / 错误 | `#00b42a` / `#ffb571` / `#ff8585` | `#087a2b` / `#9a4d00` / `#b42318` |
| 边框 | `rgba(134,144,156,.16)` | `rgba(29,33,41,.14)` |

数字使用 `Cascadia Mono` / `Consolas` 等宽字体与 `tabular-nums`；中文使用思源黑体优先，回退到系统 CJK 字体。卡片统一 8px 圆角，不使用大面积玻璃渐变、模糊或粒子装饰。

## 布局

- 页头固定贴顶，桌面 72px、手机约 60px；品牌、版本、伪熄屏、地址配置和主题按钮保持可见。
- 1280px 桌面为双栏：左侧测试设置，右侧实时带宽仪表，两卡等高且仪表垂直居中；出口地址与连通性独占一行。1080px 以下自然单栏。
- 主操作按钮 40px，手机端 44px；输入框、节点操作和弹窗关闭按钮在手机端同样满足 44px 触控目标。
- 仪表盘、统计卡、出口检测列表和节点弹窗共用同一套边框、表面和等宽数字规则。
- 仪表红框延迟显示**当前测试连接的首块响应时间**，与状态行一致；节点切换或新测试开始时清空，停止后保留最近一次结果。本站 API 首响应仍在“出口地址与连通性”列表中。

## 测速地址单列表

- 默认目录保留 119 条记录、112 个唯一 URL，使用原生 `ul/li` 及可读列表名称；不显示分组标题，不使用折叠分组。
- 搜索仅匹配名称和 URL；结果为空时给出缩短关键词或添加地址的提示。默认与速度排序视图均保持单列表，排序按钮可“恢复默认顺序”。
- 9 条原“自定义下载·域名”名称改为朝夕光年、百度1/2、爱奇艺、阿里巴巴1–4、字节跳动；其他名称保留，URL 字节和签名参数不变。
- 用户自定义节点直接追加到列表，不单独成组。选择、检测、复制、隐藏/删除、撤销和恢复操作仍可用；检测与速度排序按 URL 去重。
- 当前保存地址已被移除时，一次性迁移会切换默认节点并提示，不启动下载；其他保存名称和设置保留。

## 保留的行为

- 本轮保留表单字段、滚动/焦点逻辑、主题持久化、下载引擎、网络检测、取消和导出；节点目录、平面搜索/渲染与一次性迁移按上述规则调整。
- `theme.js` 仍按系统主题初始化，手动选择写入 `tk_theme` 并跨刷新保留；图标在深色/浅色下分别显示太阳/月亮。
- 顶部品牌版本、固定页头和测试设置/仪表等高布局保留；已移除的底部说明、页脚及连通性结果后缀不恢复。未新增网络请求、后端接口或第三方 UI 依赖。
- CSP 仍为 `script-src 'self'`，无内联脚本或第三方 UI 依赖。
