# 驾驶舱视觉层

Speedtext 的页面结构、业务字段和交互保持不变，仅将视觉层统一到联通资源驾驶舱的设计语言。

## 令牌

| 用途 | 深色 | 浅色 |
|---|---|---|
| 页面背景 | `#0c101a` | `#f4f7fb` |
| 面板 | `#121927` | `#ffffff` |
| 次级面板 / 控件 | `#182131` | `#eef2f8` |
| 主要文字 | `#e8edf5` | `#1d2129` |
| 次要文字 | `#86909c` | `#52606f` |
| 链接 / 强调 | `#86baff` | `#0e5fd8` |
| 主操作填充 | `#1677ff` | `#1668dc` |
| 正常 / 预警 / 错误 | `#00b42a` / `#ffb571` / `#ff8585` | `#087a2b` / `#9a4d00` / `#b42318` |
| 边框 | `rgba(134,144,156,.16)` | `rgba(29,33,41,.14)` |

数字使用 `Cascadia Mono` / `Consolas` 等宽字体与 `tabular-nums`；中文使用思源黑体优先，回退到系统 CJK 字体。卡片统一 8px 圆角，不使用大面积玻璃渐变、模糊或粒子装饰。

## 布局

- 页头固定贴顶，桌面 72px、手机约 60px；品牌、版本、伪熄屏、地址配置和主题按钮保持可见。
- 1280px 桌面为双栏：左侧测试设置，右侧实时带宽仪表，两卡等高且仪表垂直居中；出口地址与连通性独占一行。1080px 以下自然单栏。
- 主操作按钮 40px，手机端 44px；输入框、节点操作和弹窗关闭按钮在手机端同样满足 44px 触控目标。
- 仪表盘、统计卡、出口检测列表和节点弹窗共用同一套边框、表面和等宽数字规则。
- 仪表红框延迟显示**当前测试连接的首块响应时间**，与状态行一致；节点切换或新测试开始时清空，停止后保留最近一次结果。本站 API 首响应仍在“出口地址与连通性”列表中。

## 保留的行为

- 所有原有 HTML ID、表单字段、滚动/焦点逻辑、主题持久化、下载引擎、节点管理、网络检测和导出行为未改。
- `theme.js` 仍按系统主题初始化，手动选择写入 `tk_theme` 并跨刷新保留；图标在深色/浅色下分别显示太阳/月亮。
- `frontend/index.html` 仅增加品牌副标题、可见的“实时带宽”标题和主题太阳图标；未新增接口请求或数据存储。
- CSP 仍为 `script-src 'self'`，无内联脚本或第三方 UI 依赖。

## 验证

在最终代码上执行：

- `npm run check`：33 个 JS 文件、93 个唯一 HTML ID、161 条保留节点通过。
- `npm test`：100/100。
- `npm run test:runtime`：8/8，真实 workerd 与 ASSETS 构建通过。
- `npm run test:e2e`：52/52，桌面浅色与手机深色两项目；包含双主题 WCAG/Axe、375/844/768/1440 布局、44px 触控目标和减少动画。
- 深色页面背景 `rgb(12,16,26)`、面板 `rgb(18,25,39)`；浅色背景 `rgb(244,247,251)`、面板 `rgb(255,255,255)`；375px 无横向溢出，页头滚动贴顶。
